# --Trending-Blind-Spots
2024年3月，江城。  市自来水厂工程师张明远从跨江大桥坠亡，警方初步排除他杀。官方通报称其"涉嫌严重违纪"，网络上铺天盖地的丑闻将他钉在了耻辱柱上。  然而，同一时期城南居民陆续出现腹泻、头晕等症状，自媒体上流传着水质异常的照片和检测数据，官方却坚称**"各项指标正常"**。  你是一名网络调查员。摆在你面前的是一台装有五个调查工具的电脑：新闻浏览器、目击APP、微讯、城市电台、卷宗资料。没有人给你指路，没有教程，没有提示线。你需要自己打开每一个应用，在碎片化的信息中交叉求证、纠正假象、补全时间线，最终回答四个核心问题——  张明远究竟想举报什么？ 官方通报中被删除的关键词是什么？ 自媒体图片里藏着什么数字？ 他主动制造丑闻、选择坠桥的真正目的是什么？
